📌 OPTION 1: Script Automatique (Recommandé)
─────────────────────────────────────────────────────────────────────────

Connectez-vous au serveur puis exécutez ces commandes:

ssh FarmConnects@ndeyeas.shop

source /home/FarmConnects/.virtualenvs/env/bin/activate
cd /home/FarmConnects/ndeyeas_shop
git pull origin master
chmod +x HOTFIX_DEPLOY.sh
bash HOTFIX_DEPLOY.sh

📌 OPTION 2: Commandes Manuelles (Si Option 1 échoue)
─────────────────────────────────────────────────────────────────────────

Copiez et collez LIGNE PAR LIGNE:

# 1. Connexion
ssh FarmConnects@ndeyeas.shop

# 2. Activation environnement
source /home/FarmConnects/.virtualenvs/env/bin/activate
cd /home/FarmConnects/ndeyeas_shop

# 3. Mise à jour du code
git pull origin master

# 4. Correction manuelle du settings.py
nano ndeyas_shop/settings.py

# Dans l'éditeur nano, chercher (Ctrl+W) "ACCOUNT_LOGIN_METHODS"
# Et remplacer cette section par:

ACCOUNT_LOGIN_METHODS = {'email', 'username'}
ACCOUNT_SIGNUP_FIELDS = ['email*', 'username', 'password1*', 'password2*']
ACCOUNT_USER_MODEL_USERNAME_FIELD = 'username'

# Sauvegarder: Ctrl+O puis Entrée, Quitter: Ctrl+X

# 5. Vérification
python manage.py check

# 6. Migrations
python manage.py migrate shop

# 7. Redémarrage
touch /var/www/ndeyeas_shop_uwsgi.ini

📌 OPTION 3: Correction Ultra-Rapide (Une seule commande)
─────────────────────────────────────────────────────────────────────────

Après connexion SSH, copiez TOUT d'un coup:

source /home/FarmConnects/.virtualenvs/env/bin/activate && cd /home/FarmConnects/ndeyeas_shop && git pull origin master && python3 -c "
import re
with open('ndeyas_shop/settings.py', 'r') as f: content = f.read()
content = re.sub(r'ACCOUNT_LOGIN_METHODS\s*=\s*\{[^}]+\}', \"ACCOUNT_LOGIN_METHODS = {'email', 'username'}\", content)
content = re.sub(r'ACCOUNT_SIGNUP_FIELDS\s*=\s*\[[^\]]+\]', \"ACCOUNT_SIGNUP_FIELDS = ['email*', 'username', 'password1*', 'password2*']\", content)
content = re.sub(r'ACCOUNT_USER_MODEL_USERNAME_FIELD\s*=\s*[^\n]+', \"ACCOUNT_USER_MODEL_USERNAME_FIELD = 'username'\", content)
with open('ndeyas_shop/settings.py', 'w') as f: f.write(content)
print('✅ Settings corrigé')
" && python manage.py check && python manage.py migrate shop && touch /var/www/ndeyeas_shop_uwsgi.ini && echo "✅ DÉPLOIEMENT TERMINÉ - Vérifiez https://www.ndeyeas.shop/"

🔍 Vérification Post-Déploiement
─────────────────────────────────────────────────────────────────────────

1. Visitez: https://www.ndeyeas.shop/
2. La page d'accueil doit charger sans erreur
3. Cliquez sur une image de produit → doit ouvrir la page détail
4. Testez l'ajout au panier
5. Allez sur /admin et essayez d'ajouter un produit (pas de champ quantité)

❌ En cas d'erreur
─────────────────────────────────────────────────────────────────────────

Consultez les logs:
sudo journalctl -u uwsgi -n 50 --no-pager

Redémarrage complet:
sudo systemctl stop uwsgi
sudo systemctl start uwsgi
sudo systemctl status uwsgi
